# Documentation

This directory contains all documentation for the trading bot system.

## Structure

- `architecture.md` - System architecture overview and module structure
- `modules.md` - Detailed documentation for each module
- `decisions.md` - Design decisions and rationale
- `development.md` - Development guidelines and standards
- `roadmap.md` - Development timeline and future plans

## How to Contribute

1. Follow the existing documentation style
2. Update relevant documentation when making changes
3. Keep documentation in sync with code changes
4. Use clear, concise language

## Documentation Standards

- All public APIs must have comprehensive docstrings
- Code comments should explain "why" not "what"
- Include examples where appropriate
- Maintain version control of documentation
